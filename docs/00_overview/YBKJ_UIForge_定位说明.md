# YBKJ-UIForge 定位说明

YBKJ-UIForge 是友邦科技智慧维保体系与个人项目共用的 UI 锻造库。

它不是某一个项目的前端代码仓库，而是用于沉淀可迁移、可复用、可审计的 UI 设计方法、AI 协同开发规则和项目迁移模板。

## 两类服务对象

### 1. 友邦科技智慧维保项目

重点关注：

- 工业维保专业感
- 智慧消防场景
- 设备码
- 地图点位
- 网络诊断
- 视频监控
- 报告中心
- 证据链
- Mock / 脱敏 / 只读边界
- 验证状态分级

### 2. 个人项目

重点关注：

- 去 AI 模板化
- 视觉统一
- 落地页优化
- 通用组件思路
- Codex / Trae 提示词
- 项目初始化规则

## 当前策略

第一阶段不追求大而全。

先从 YBKJ-LinkScope-V2 的 Week 1 Design Shell Baseline 试点中提炼出已验证的规则、tokens、组件和迁移步骤。
