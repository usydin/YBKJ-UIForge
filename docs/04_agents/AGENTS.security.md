# AGENTS.security.md

## Security Boundary Rules

- Do not include real IP addresses, GPS coordinates, passwords, tokens, or real asset data.
- Do not develop write, control, firmware, cracking, bypassing, or brute-force features for industrial devices.
- Mock data must be local, static, and clearly marked.
- Evidence records should include source, time, hash, version, and operator.
- Verification status must be explicit: simulated, VM verified, real-device verified, or field verified.
